# Напоминания и команды бота

Один процесс читает `homework.json`, в 16:00 по Москве (13:00 UTC) шлёт напоминание, если срок завтра, и отвечает на `/homework` и `/add`.

Секреты только в переменных окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Локально их можно положить в `C:\ForMe\telegram\.env` (файл не коммитится). На Railway их задают в настройках сервиса.

Проверка без отправки в Telegram:

```powershell
python C:\ForMe\homework\main.py --dry-run
```

Новая домашка в файле — объект с полями `subject`, `topic`, `deadline` (`YYYY-MM-DD`), `number` по желанию. Из Telegram:

```text
/add Предмет | Тема | 2026-11-01 | 12
```

## Railway

1. В Railway создай проект и подключи этот репозиторий. Корень сервиса — корень репозитория, отдельно папку указывать не нужно.
2. В Variables добавь `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. В репозиторий их не клади.
3. Deploy. Процесс должен оставаться запущенным: он сам опрашивает Telegram.
4. Напиши боту `/homework`. В ответе должен быть список, включая кибербезопасность и срок `2026-10-30`.
5. Локальную задачу Windows «ForMe Homework Reminder» не включай снова, иначе напоминание может уйти дважды.
